Matriks dokumen dan sumber pemeriksaan

Tautan “Detail” menuju prototipe ini. Tombol PDF menggunakan salinan lokal jika tersedia; jika tidak, langsung ke file resmi JDIH. Bukti hash salinan tertera pada berkas manifest.

Kebutuhan pengembangan untuk Pusdatin

  1. API katalog per kategori: endpoint berhalaman untuk daftar, pencarian dan filter jenis/tahun/nomor/status, dengan ID dokumen stabil dan tanggal pemutakhiran.
  2. Dokumen PDF: penyimpanan file resmi, URL unduh dan pratinjau yang tidak kedaluwarsa, serta checksum berkas dan pengendalian perubahan.
  3. Metadata dan abstrak: skema terpisah untuk peraturan, putusan/yurisprudensi, monografi, dan artikel sesuai Permenkumham Nomor 8 Tahun 2019. Dokumen pembentukan PUU serta keputusan/kerja sama perlu pemetaan khusus.
  4. Validasi status: hindari menyamakan status “Berlaku” untuk peraturan dengan status berkekuatan hukum tetap suatu putusan; definisikan kamus status dan relasi hukum.
  5. Kualitas data dan pembaruan: verifikasi field wajib, riwayat sunting, petugas pengesahan, sinkronisasi JDIHN, log dan penanganan file gagal.
  6. Integrasi operasional: CMS untuk berita, layanan kontak, galeri, statistik kunjungan, survei kepuasan, autentikasi pengguna, dan aksesibilitas.

Laporan ini adalah dokumentasi prototipe, bukan berita acara pemenuhan standar atau hasil penilaian resmi.
