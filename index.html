PROGRAM KEMENTERIAN

Mengenal Program Unggulan 5T

Lima inisiatif penguatan kawasan, sumber daya manusia, dan pembangunan transmigrasi.

PROGRAM 01

Trans Tuntas

Tuntas lahan, tuntas harapan. Penyelesaian persoalan lahan, kepastian hak, dan optimalisasi pemanfaatan lahan.

PROGRAM 02

Transmigrasi Lokal

Penguatan ekonomi dan infrastruktur masyarakat melalui potensi lokal dan pengembangan kawasan.

PROGRAM 03

Transmigrasi Patriot

Penguatan kader pembangunan, keterampilan, dan kapasitas komunitas di kawasan transmigrasi.

PROGRAM 04

Trans Karya Nusantara

Pengembangan ekonomi kawasan, kemitraan, industri unggulan lokal, dan lapangan kerja.

PROGRAM 05

Trans Gotong Royong

Pembangunan kawasan secara kolaboratif untuk memperkuat ekonomi, infrastruktur, dan harmoni sosial.
